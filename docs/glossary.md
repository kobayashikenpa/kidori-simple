# 画面の用語一覧

画面に出る言葉と、その意味の一覧。オーナーが「現場の言い方」を確認し、決まったものから画面に反映する。

- **いまの言葉**：画面に出す予定の言葉（仕様書第1版の言葉）
- **現場の言い方**：オーナーが決めた言葉（空欄と「そのまま」は、いまの言葉のまま）

## 仕事と入力

| いまの言葉 | 意味 | 現場の言い方 |
|---|---|---|
| 仕事 | 1回の木取りの入力のまとまり。設定・部材をまとめて保存する。新しい仕事はいつも初めの設定から（コピーは元の設定のまま）。新しい仕事の名前の初めは「10/25 仕事」（月/日 仕事。第1.6版） | |
| 部材 | 板から切り出すパーツ（天板、側板、棚板など） | |
| 全体（寸法だけの行） | 切り出さず、寸法だけを持つ行（枚数 0。木取りのタブでは「切らない」）。第2.2版から式で使うことはない | |
| 幅・長さ（W・H） | 部材の板の面の2つの寸法。画面では W を「幅」、H を「長さ」と出す（第2.3版。保存データの中は W・H のまま）。数字（小数も可。0 は使えない）か、数字と ＋ − × ÷ ( ) だけの式（第2.3版） | 幅・長さ（2026-11-05 オーナー） |
| 式 | 幅・長さに入れる、数字と ＋ − × ÷ ( ) だけの計算（例：450−50、(900−18)÷2）。× ÷ が先、( ) の中が先。表には計算した値を出す。「＝」は付けない。部材の寸法・調整寸法は使えない（第2.3版。第2.2版でいったんなくした）。前の版の部材の寸法・調整寸法を使った式は、開いたとき・ファイルを取り込んだときに計算した数字に置き換える | |
| 枚数 | その部材を何枚切り出すか | |
| 回転しない／回転してよい | 回転しない：幅を板の妻手、長さを板の長手に合わせて置く。回転してよい：向きを変えて置いてもよい | |
| 複製 | 同じ仕事の中で、部材を1つ写して足す（名前は「◯◯のコピー」） | |
| 履歴・履歴に残す | 木取りの画面で、メモを付けてその時の設定と部材を仕事の中に残す（最大20件）。メモが無ければ「メモなし」（第2.1版） | |
| この内容に戻す | 履歴の設定と部材に置き換える。切り出しチェックと固定した1枚は外れる（第2.1版） | |

| いまの言葉 | 意味 | 現場の言い方 |
|---|---|---|
| 仕上がり寸法（［仕上がり］のタブ） | 家具として完成したときの寸法。入力はこちらだけ | |
| 木取り寸法（［木取り］のタブ） | パネルソーで切る寸法（仕上がり寸法 ＋ 切り代）。見るだけ | |
| 切り代 | あとで削り仕上げるための余分。幅・長さに同じだけ足す（初期値 0mm。第2.3版） | |
| 調整寸法（メラミン1・シート0.5・逃げ・ほぞ など） | （第2.2版でなくした。調整寸法の表も無い。逃げ・ほぞなどは足し引きした数字か、450−50 のような式を幅・長さに入れる） | |

## 第1.6版で増えた言葉

| いまの言葉 | 意味 | 現場の言い方 |
|---|---|---|
| ＝（式） | （第2.2版でなくした。キーに「＝」は無い）キーの「＝」を押してから入れると式になる（エクセルと同じ）。キーの上の行に「＝天板.W − 20」のように「＝」を付けて出す。保存する式には「＝」を付けない。部材の寸法・調整寸法を使っている式は、もう一度入力すると「＝」付きで開く。カーソルが先頭のときに 1字消す を押すと「＝」が消え、式でない入力に戻る。数字や計算（1800 − 40）は「＝」なしでも入れられる | |
| セルを押して寸法を入れる | （第2.2版でなくした）「＝」で始めた入力中に、ほかの部材の W・H のセルを押すと、その寸法（例：天板.W）がカーソルの位置に入る。入力しているセルはそのまま。式に入っている部材のセルは色の点線の枠で示す（部材ごとに色が変わる）。名前の無い部材は入れられない（先に名前を入れる）。第1.5版までのキーの「部材」のタブはなくした | |
| 1字消す（⌫）・次へ（↵） | キーの右上の ⌫ はカーソルの前を1つ消す。右下の青い「次へ」は 名前 → 幅 → 長さ → 枚数 → 次の行 と進む（スマホの数字キーボードと同じ並び。第2.2版は「次へ」と「閉じる」が2段の高さ、第2.3版から1段） | |
